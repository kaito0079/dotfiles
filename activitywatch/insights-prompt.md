標準入力で渡す JSON は、直近の作業記録を aw-collect.py で集計したもの。
これをもとに、繰り返している作業をショートカットやコマンドにする案を出してほしい。

## JSON の中身

- `window`: アプリとウィンドウタイトルの利用時間・訪問回数、アプリ切り替えの 2 連・3 連の回数
- `web`: ドメインごとの利用時間、よく開くページ、ドメイン間の行き来 (null ならブラウザの記録なし)
- `shell`: 自分で打ったコマンドの回数、先頭 2 語の回数、連続して打ったコマンドの並び、
  cmux ワークスペースごとの内訳 (null なら記録なし)
- `claude`: Claude Code のセッションごとの作業時間・ディレクトリ・ブランチ、最近の依頼文、
  スラッシュコマンド、ツールの利用回数、Claude が実行した Bash コマンドの回数と並び
- `window` と `web` は離席していない時間に限った値
- コマンドの並びはタブ (cmux のサーフェス) や Claude のセッションごとに数えており、
  並行して進めている別の作業が混ざった並びではない
- ターミナルでの作業の多くは Claude に任せているため、`shell` は少なく `claude` が多いのが普通

## 進め方

1. カレントディレクトリは dotfiles リポジトリ。提案する前に、既にある仕組みを Read / Grep で確認する。
   - `hammerspoon/.hammerspoon/` (ホットキー・ウィンドウ配置)
   - `zsh/aliases.zsh`、`zsh/.config/zsh/` (エイリアス・関数・キーバインド)
   - `raycast/`、`claude/.claude/settings.json` (許可リスト・フック)
   - `claude-tools/skills/`、`claude-tools/agents/` (スキル・エージェント)
   既にショートカットがある作業は、案に含めず「既存の手段を使っていない可能性」として別に挙げる。
   Raycast のホットキーは Raycast 内に暗号化して保存されていて読めない。
   アプリの切り替えや起動を提案するときは「Raycast で登録済みなら、使えていない可能性」と添える。
2. 効果が大きい順に最大 5 件を提案する。効果は「回数 × 1 回あたり省ける時間」で見積もる。
   自分の手の操作 (`window` / `web` / `shell`) と、Claude への頼み方 (`claude`) の両方から探す。
   後者は、同じ趣旨の依頼の繰り返しをスラッシュコマンドやスキルにする、毎回実行している
   前準備を CLAUDE.md やフックにまとめる、などを想定する。
3. データが少なすぎて傾向が読めないときは、無理に案を作らずその旨だけを書く。

## 出力

Markdown だけを出力する (前置きや締めの挨拶は不要)。

```
# 繰り返し作業の分析 (<期間>)

## 概要
<期間中の作業傾向を 3 行以内で>

## 提案
### 1. <案の名前>
- 根拠: <JSON の数値をそのまま引用>
- 手段: hammerspoon / zsh 関数 / エイリアス / Raycast / Claude のスキル・コマンド / CLAUDE.md / フック / その他
- 置き場所: <リポジトリ内のファイルパス>
- 実装例:
  <そのまま貼れるコード>
- 見積もり: <週あたりの削減時間>

## 既存の手段を使っていない可能性
<該当なしなら省略>
```

- 案はそれぞれ単体で完結させ、既存の命名・書き方に合わせる。
- ファイルは編集しない。採用するかどうかは読んだ人が決める。
